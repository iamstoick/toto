# bench/baseline.txt — benchmark medians (ms) for regression flagging
# (`scripts/bench.sh --baseline`). Sources: benchmark rows are the
# Stage 1 published medians (n=5, methodology in the Phase 7 report
# §Stage 1); `aot*-wf-*` and `start-*` rows were measured locally on
# 2026-11-17 (Ryzen 5 5600G, 27 GB RAM, Linux, rustc 1.100.0, n=5 for
# wordfreq Off, n=3 for the rest); `exec-gc-*` rows are debug-executor
# medians measured locally on 2026-11-18 (same machine, n=3) — the GC
# workloads run on the runtime executor (debug `toto`), not AOT.
# `exec-refsvc-load` is the reference-service load row (60 authed
# requests over concurrent TLS + phase-A pool contention, ~65 s
# debug-executor): median measured locally on 2026-11-23 (12-core
# x86_64, 27 GB RAM, Linux, rustc 1.100.0, n=3). Wave 3 F1
# fix-forward: Phase C went sequential → concurrent (conc=2,
# the deterministic envelope); wall time unchanged in scale.
# CI compares `--runs 3` medians against these; any median above 5x
# its baseline prints FLAG and fails the suite (exit 1). The 5x rule
# absorbs machine variance (CI runners differ from the recording
# machines) while catching order-of-magnitude regressions (the
# wordfreq 75s anomaly was ~500x its fixed time).
